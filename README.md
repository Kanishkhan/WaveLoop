# WaveLoop

A professional working-asset prototype for the NxtWave Growth Challenge: a referral-first registration and growth engine for **Build Your First AI Project in 60 Minutes**.

## Highlights
- High-conversion workshop landing page
- 30-second registration flow
- Automatic source/referral attribution
- Personal referral link + WhatsApp share
- Referral progress and milestone model (1 / 3 / 5)
- Interactive project-fit finder
- Workshop experience switcher (Define / Build / Explain)
- Operator command center
- 7-day campaign simulation
- Channel mix and budget-decision cue
- Multilingual message lab (English / Tamil / Telugu)
- Demo registration seeding + CSV export
- Light/dark theme
- Responsive design

## Run locally
```bash
python -m http.server 8000
```
Open http://localhost:8000

Command center: http://localhost:8000/admin.html

## Notes
This prototype uses browser localStorage for demo persistence. The campaign numbers are simulation/model output, not real campaign results. No students were contacted.
